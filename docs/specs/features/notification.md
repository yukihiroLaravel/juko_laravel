## 目的

講師が講座の受講生に向けて出すお知らせの作成・掲示・確認までを定める。共通仕様は `docs/specs/conventions.md`、認可は `docs/specs/features/authorization.md` に従う。

## 関連コンテキスト

主に `shared`（BR-SHARED-014・BR-SHARED-015・BR-SHARED-006）。

## お知らせの作成と更新

1. `AC-NOTIF-001` お知らせは講座を指定して作成しなければならない (BR-SHARED-014)。
2. `AC-NOTIF-002` お知らせの作成には、題名・本文・種類・公開状態・掲示を始める日時・掲示を終える日時の指定を必須としなければならない。
3. `AC-NOTIF-003` 掲示を終える日時は、掲示を始める日時より後でなければならない。満たさないときは 422 を返す。
4. `AC-NOTIF-004` 題名は 50 文字以内、本文は 500 文字以内としなければならない。
5. `AC-NOTIF-005` 種類は常時表示または一度きりのいずれかとしなければならない (BR-SHARED-015)。
6. `AC-NOTIF-006` 公開状態は公開または非公開のいずれかとしなければならない。作成時に指定がない場合は非公開として扱う。
7. `AC-NOTIF-007` 作成したお知らせの持ち主は操作者自身の講師としなければならない。以後の閲覧・更新・削除の権限はこの持ち主で判定する (AC-AUTHZ-004)。
8. `AC-NOTIF-008` お知らせの更新では、題名・本文・種類・公開状態・掲示期間を変更できなければならない。講座の変更はできない。

## お知らせの一括操作

9. `AC-NOTIF-009` 講師は、選択した複数のお知らせに対して種類の変更・公開状態の変更・削除をまとめて行えなければならない。
10. `AC-NOTIF-010` 講師は、自分が持つすべてのお知らせに対して種類の変更と公開状態の変更をまとめて行えなければならない。この操作は対象の指定を受け取らない。
11. `AC-NOTIF-011` マネージャーは、自分と配下の講師が持つすべてのお知らせに対して種類の変更と公開状態の変更をまとめて行えなければならない (BR-SHARED-003)。
12. `AC-NOTIF-012` 一括操作の対象に操作者の権限の範囲外のお知らせが1件でも含まれるとき、システムは 403 を返し、1件も変更してはならない (AC-COMMON-016)。
13. `AC-NOTIF-013` お知らせを削除したとき、システムは受講生の確認済みの記録を併せて削除しなければならない。

## 受講生に見せるお知らせ

14. `AC-NOTIF-014` 受講生向けの一覧は、次のすべてを満たすお知らせだけを返さなければならない。

| 条件 |
|---|
| 操作者が受講している講座のお知らせであること |
| 公開されていること |
| 現在時刻が掲示を始める日時以降かつ掲示を終える日時以前であること (BR-SHARED-014) |
| 講座が期限なしであるか、操作者のその講座の受講期限が到来していないこと (BR-SHARED-006) |

15. `AC-NOTIF-015` 受講生向けの一覧の並び替えは、題名・講座・掲示を始める日時・講師の呼び名のいずれかで指定できなければならない。既定は掲示を始める日時の昇順とする。
16. `AC-NOTIF-016` 講師の呼び名で並び替えるとき、同じ呼び名のお知らせの順序を安定させなければならない。
17. `AC-NOTIF-017` 受講生向けの一覧は、既読と未読の絞り込み条件を受け付けるが、結果には反映しない（Q-009）。
18. `AC-NOTIF-018` 受講生向けの応答には、講座名と講師の呼び名を含めなければならない。
19. `AC-NOTIF-019` 受講生向けの詳細は、公開されているお知らせに限り返さなければならない。非公開のものは 404 を返す。
20. `AC-NOTIF-020` 受講生向けの詳細で、操作者がその講座を受講していないとき、システムは 404 を返さなければならない。
21. `AC-NOTIF-021` 受講生向けの詳細で、操作者のその講座の受講期限を過ぎているとき、システムは 403 を返さなければならない (AC-AUTHZ-008)。
22. `AC-NOTIF-022` 受講生向けの詳細の応答には、その受講の期限日を含めなければならない。

一覧と詳細で受講期限の判定がそろっておらず、期限当日のお知らせは一覧に現れないが詳細は開ける。この扱いは Q-013 として確認中である。

## 確認済みの記録

23. `AC-NOTIF-023` 確認済みの記録は、種類が一度きりのお知らせに対してのみ受け付けなければならない。常時表示のお知らせを指定されたときは 404 を返す (BR-SHARED-015)。
24. `AC-NOTIF-024` 確認済みの記録で、操作者がその講座を受講していないとき、システムは 404 を返さなければならない。
25. `AC-NOTIF-025` 確認済みの記録で、操作者のその講座の受講期限を過ぎているとき、システムは 403 を返さなければならない。
26. `AC-NOTIF-026` すでに確認済みのお知らせに対して再度の記録が要求されたとき、システムは重複して記録せず、成功として応答しなければならない。

## 講師に見せるお知らせ

27. `AC-NOTIF-027` 講師向けの一覧は、操作者自身が持つお知らせだけを返さなければならない。
28. `AC-NOTIF-028` マネージャー向けの一覧は、自分と配下の講師が持つお知らせを返さなければならない (BR-SHARED-003)。
29. `AC-NOTIF-029` 講師向けの一覧の応答には、講座名・タグ・受講期限の設定と、その講座で受講中の受講生数を含めなければならない (AC-ANALYTICS-045)。

## 対象外

- お知らせのメール送信・プッシュ通知
- 受講生ごとの個別のお知らせ
- 講座をまたいだ全体向けのお知らせ
- 常時表示のお知らせに対する確認済みの記録
- 掲示期間の自動延長
