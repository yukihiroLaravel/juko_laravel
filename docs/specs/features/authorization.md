## 目的

誰がどの対象を操作できるかを定める。共通仕様は `docs/specs/conventions.md` に従い、ここでは差分だけを書く。

## 関連コンテキスト

主に `shared`（BR-SHARED-001・BR-SHARED-003・BR-SHARED-006・BR-SHARED-009）。

## 講師が扱える範囲

1. `AC-AUTHZ-001` 講師として要求があったとき、システムはその講師が担当する講座に属する対象のみを操作させなければならない (BR-SHARED-001)。
2. `AC-AUTHZ-002` マネージャーとして要求があったとき、システムは自分が担当する講座に加えて、配下の講師が担当する講座に属する対象も操作させなければならない (BR-SHARED-003)。
3. `AC-AUTHZ-003` 配下でない講師が担当する対象への操作は、マネージャーであっても 403 を返さなければならない。
4. `AC-AUTHZ-004` 講座に属する対象（チャプター・レッスン・お知らせ・受講）の判定は、その対象がたどり着く講座の担当講師で行わなければならない。
5. `AC-AUTHZ-005` タグと講師情報の判定は、講座を経由せず、そのタグを作成した講師およびその講師本人で行わなければならない。

## 受講生が扱える範囲

6. `AC-AUTHZ-006` 受講生として要求があったとき、システムは本人の受講のみを操作させなければならない。
7. `AC-AUTHZ-007` 受講している講座が公開されていないとき、システムは受講内容の閲覧を拒否し 403 を返さなければならない (BR-SHARED-009)。
8. `AC-AUTHZ-008` 受講期限を過ぎているとき、システムは受講内容の閲覧とお知らせの閲覧を拒否し 403 を返さなければならない (BR-SHARED-006)。
9. `AC-AUTHZ-009` 受講生に見せる講座の内容は、公開されているチャプターと、そのチャプターに属する公開されているレッスンに限らなければならない (BR-SHARED-009)。

## 操作ごとの判定

| 操作 | 判定 |
|---|---|
| 講座の閲覧・更新・削除・一括操作 | 担当講師またはそのマネージャー |
| チャプター・レッスンの作成・更新・削除・並び替え | 属する講座の担当講師またはそのマネージャー |
| お知らせの作成・閲覧・更新・削除 | お知らせを作成した講師またはそのマネージャー |
| タグの閲覧・更新・削除 | タグを作成した講師またはそのマネージャー |
| 受講の登録・削除 | 対象講座の担当講師またはそのマネージャー |
| 受講状況の講師側閲覧 | 対象講座の担当講師またはそのマネージャー。かつ受講期限内であること |
| 受講生情報の講師側閲覧 | その受講生が、操作者が担当する講座（マネージャーは配下を含む）のいずれかを受講していること |
| 講師情報の閲覧・更新 | 本人、またはその講師を配下に持つマネージャー |
| 受講内容の閲覧・進捗の取得 | 本人・公開されている講座・受講期限内 |
| チャプター単位・講座単位でまとめて完了にする | 本人・公開されている講座 |
| レッスンの受講状況を1件ずつ更新する | 本人 |

10. `AC-AUTHZ-010` 講師が受講状況を閲覧するとき、対象の受講が期限を過ぎている場合は 403 を返さなければならない。

期限切れの受講に対する講師側の閲覧制限は BR-SHARED-006 の受講生側の制限を講師にも適用したものである。受講の削除は期限切れでも行える。

まとめて完了にする操作と1件ずつ更新する操作で判定がそろっていない点は Q-004 として確認中である。確定するまで現状の判定を変更しない。

## 対象の取り違えを防ぐ検証

11. `AC-AUTHZ-011` 講座を指定してチャプターを一括操作するとき、システムは指定されたチャプターがすべてその講座に属することを確認しなければならない。属さないものが含まれるときは 403 を返す。
12. `AC-AUTHZ-012` チャプターを指定してレッスンを一括操作するとき、システムは指定されたレッスンがすべてそのチャプターに属することを確認しなければならない。属さないものが含まれるときは 403 を返す。
13. `AC-AUTHZ-013` 受講しているチャプターを完了にするとき、システムはそのチャプターが対象の受講の講座に属し、かつ公開されていることを確認しなければならない。満たさないときは 403 を返す。
14. `AC-AUTHZ-014` タグで一覧を絞り込むとき、システムは指定されたタグが操作者の扱える範囲にあることを確認しなければならない。範囲外のときは 403 を返す。

## 一覧取得における範囲の絞り込み

15. `AC-AUTHZ-015` 一覧の取得では、権限のない対象を除いた結果を返さなければならない（権限のない対象が含まれることを理由に 403 としない）。
16. `AC-AUTHZ-016` 講師向けの受講生一覧は、マネージャーであっても操作者本人が担当する講座の受講生だけを返す。配下の講師の受講生はマネージャー向けの受講生一覧で取得する（Q-001）。

## 対象外

- 講師どうしの権限の委譲
- 受講生による他の受講生の情報の閲覧
- 担当講師の付け替え
