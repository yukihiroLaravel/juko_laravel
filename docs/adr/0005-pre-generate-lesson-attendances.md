# ADR-0005 受講状況を未着手の分まで先に作る

## ステータス

承認済み (2026-08-17 記録)

この決定は実装済みの設計を後から記録したものである。決定そのものは記録日より前に行われている。

## 背景

受講生ごとの進捗は「完了したレッスン数 / 対象のレッスン数」で表す。受講状況を学習開始時に作る方式（遅延生成）だと、分母をレッスン側から数え、分子を受講状況側から数えることになり、公開状態の変化のたびに両者の対象範囲を合わせ続ける必要がある。

候補は (a) 受講生がレッスンを開き始めた時点で受講状況を作る・(b) 受講の登録時に、下書きでないレッスンの分をまとめて作る である。

## 決定

受講の登録時に、下書きでないレッスン（公開・非公開のいずれも）の受講状況を未着手として作る。加えて、レッスンが下書きから公開に変わった時点で、その講座の既存の受講生全員分を作る。

## 理由

- 受講状況が全件そろっていれば、進捗は受講状況の件数の比較で算出でき、分母と分子の対象範囲が一致する
- 未着手の受講生を把握できる。要フォローやつまずき箇所の集計は「まだ着手していない」ことを必要とする
- 非公開のレッスンの分も作るのは、非公開から公開に戻したときに生成漏れを起こさないためである
- (a) は受講状況が存在しないことと未着手であることを区別できず、集計の分岐が増える

## 影響

- 受講の登録とレッスンの公開の2か所に生成処理が必要になる。どちらかが漏れると進捗が実態とずれる
- 生成時に既存の組み合わせを除外する必要がある。同じレッスンを非公開と公開のあいだで往復させても二重に作らない
- 受講生が多い講座でレッスンを公開すると、受講生数の分のレコードを一度に作る
- 講師が受講生を代理登録する経路では生成していないため、この前提が崩れている（Q-011）
- レッスンの一括状態変更では生成していない。下書きを対象から除外しており、下書きから公開への遷移が起きないためである（ADR-0004）
