# ADR-0004 公開状態の遷移を制限し、下書きへ戻さない

## ステータス

承認済み (2026-08-17 記録)

この決定は実装済みの設計を後から記録したものである。決定そのものは記録日より前に行われている。

## 背景

講座・チャプター・レッスンは下書き・公開・非公開の3状態を持つ。公開すると受講生に届き、レッスンの公開は受講状況の生成を伴う。状態を自由に行き来できると、受講状況が存在するのに下書きに戻ったレッスンが生まれ、進捗の分母が状態によって揺れる。

候補は (a) 3状態を自由に遷移させる・(b) 下書きから公開への一方向のみを許し、公開と非公開の間だけを往復させる である。

## 決定

遷移は下書きから公開への一方向、および公開と非公開の相互のみを許す。同じ状態への変更は何もしない。許されない遷移が要求されたときは検証で拒否する。

## 理由

- 公開を取り下げたい要求は非公開で満たせる。非公開は受講状況を保ったまま受講生から隠せる
- 下書きへ戻せると、受講状況の生成が済んだレッスンを未生成の状態と区別できなくなる
- 一括操作でも同じ検証を通すことで、対象のうち1件でも許されない遷移があれば全体を中止でき、中途半端な状態を作らない

## 影響

- 公開したものを完全に作り直したい場合は、削除して作り直す。ただし受講状況が存在するものは削除できない
- レッスンの一括状態変更では下書きのレッスンを対象から除外している。除外しないとこの制約に触れて全体が失敗するためである
- 除外は成功として扱うため、一括操作で下書きのレッスンが公開されないことを呼び出し側が知っている必要がある
