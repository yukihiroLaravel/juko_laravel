### Q-004 期限切れ・非公開の講座で学習を続けられてよいか

|---|---|
| 状態 | 未確定 |
| 担当 | 未定 |
| 確認先 | 未定 |

講座の内容を見る操作は、受講期限を過ぎているか講座が非公開であれば拒否する。一方、学習の記録を更新する操作は拒否の条件がそろっていない。

BR-SHARED-006 と BR-SHARED-009 に照らすと、いずれの更新も拒否すべきに見える。一方で、学習の途中で講座が非公開になった受講生や期限直前の受講生の救済として意図的に許している可能性もある。

### Q-011 講師が代理登録した受講生に受講期限と受講状況を用意するか

講師が受講生を代理登録して同時に受講させる場合（BR-SHARED-021）、その受講には受講期限が設定されず、レッスンごとの受講状況も作られない。講座に期限の決め方が設定されていても期限なしとして扱われ、受講生が学習を始めても記録する先がない状態になる。既存の受講生を登録する経路では、いずれも用意している。

| 項目 | 内容 |

| 実装保留 | 期限と受講状況を用意する仕様に変えるかが決まるまで、この経路の登録処理は変更しない |

### Q-012 受講期限の一括変更をどこまで反映するか

| 項目 | 内容 |
|---|---|
| 状態 | 未確定 |
| 担当 | 未定 |
| 確認先 | 未定 |
| 期限 | 未定 |

受講期限の決め方は、講座を1件ずつ更新する操作では講座の設定と受講生の期限の両方に反映されるが、複数の講座に対する一括変更では講座の期限の設定だけが書き換わり、講座が持つ決め方の区分と受講生ごとの期限は変わらない。マネージャーが行う期限の取り消しも、受講生の期限は変わらない。BR-SHARED-005 の「決め方を変えたら受講生の期限も引き直す」に対して、一括操作の範囲が定まっていない。

| 項目 | 内容 |
|---|---|
| 影響範囲 | BR-SHARED-005・`docs/specs/features/enrollment.md` |
| 暫定方針 | 現状の振る舞いを維持する。一括変更後に受講生の期限を揃える必要がある場合は、講座を1件ずつ更新する操作を使う |
